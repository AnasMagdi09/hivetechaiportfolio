1. الهيكل العام (Structure)
--------------------------------------------------------------------------------
الصفحة مبنية بـ HTML5 semantic مع دعم RTL للعربية:
- <html lang="ar" dir="rtl"> - دعم اللغة العربية والاتجاه من اليمين لليسار
- الأقسام الرئيسية: Header → Hero → Stats → Filter → Projects → Footer

الملفات المستخدمة:
- index.html (الهيكل)
- css/main.css (الستايل الرئيسي)
- css/animations.css (الأنيميشن)
- css/responsive.css (التجاوب)
- js/main.js (المنطق الرئيسي)
- js/animations.js (إدارة الأنيميشن)
- js/background-particles.js (الجسيمات)
- js/neural-network.js (مسار الكرة)
- js/language.js (نظام اللغات)
- js/projects-data.js (بيانات المشاريع)

3. شريط التمرير (Scrollbar)
--------------------------------------------------------------------------------
مخفي تماماً في الصفحة الرئيسية (index.html):

  html::-webkit-scrollbar {
      width: 0 !important;
      height: 0 !important;
      display: none !important;
  }
  
  html {
      scrollbar-width: none;      /* Firefox */
      -ms-overflow-style: none;   /* IE and Edge */
  }

في الصفحات الأخرى يظهر بتصميم مخصص:

  ::-webkit-scrollbar {
      width: 8px;
  }
  
  ::-webkit-scrollbar-track {
      background: var(--bg-secondary);  /* #12121a */
  }
  
  ::-webkit-scrollbar-thumb {
      background: var(--gradient-primary);  /* تدرج بنفسجي */
      border-radius: 9999px;
  }


4. تأثيرات الخلفية (Background Effects)
--------------------------------------------------------------------------------

أ. الشبكة (Grid Pattern):
   - شبكة خفيفة جداً بلون بنفسجي شفاف
   - حجم المربعات: 50×50 بكسل
   - الشفافية: 3% فقط
   
   .bg-grid {
       background-image: 
           linear-gradient(rgba(99, 102, 241, 0.03) 1px, transparent 1px),
           linear-gradient(90deg, rgba(99, 102, 241, 0.03) 1px, transparent 1px);
       background-size: 50px 50px;
       position: fixed;
       z-index: -1;
   }

ب. الجسيمات المتحركة (Particles) - ملف background-particles.js:
   - Canvas منفصل يغطي كل الشاشة
   - عدد الجسيمات: 50 جسيم
   - المسافة القصوى للاتصال: 150px
   - سرعة الحركة: 0.3
   - الألوان: بنفسجي، سماوي، وردي
   - تأثير نبض (pulse) على كل جسيم
   - خطوط اتصال بين الجسيمات القريبة
   - الشفافية: 50%

ج. مسار الكرة المتحركة (Snake Track) - ملف neural-network.js:
   - كرة تتحرك على مسار متعرج على يمين الشاشة
   - تتبع موضع الـ scroll (من أعلى لأسفل)
   - المسار: 4 منحنيات متعرجة
   - عرض المسار: 35px
   - حجم الكرة: 16px radius
   - تدرج المسار: سماوي → بنفسجي → وردي
   - تأثير توهج على الكرة
   - مخفي على الموبايل (أقل من 768px)
   - الحركة سلسة مع easing: 0.2


5. الأنيميشن والتأثيرات
--------------------------------------------------------------------------------

أ. تأثير الطفو (Float Animation):
   @keyframes float {
       0%, 100% { transform: translateY(0); }
       50% { transform: translateY(-20px); }
   }
   - المدة: 6 ثواني
   - يُستخدم على: Hero Mascot، Footer Mascot، الأشكال الزخرفية

ب. تأثير النبض (Pulse Animation):
   @keyframes pulse {
       0%, 100% { transform: scale(1); opacity: 0.15; }
       50% { transform: scale(1.1); opacity: 0.25; }
   }
   - المدة: 8 ثواني
   - يُستخدم على: خلفية Hero، الأيقونات

ج. تأثير الظهور عند التمرير (Reveal on Scroll):
   .reveal {
       opacity: 0;
       transform: translateY(50px);
       transition: all 0.8s cubic-bezier(0.25, 0.46, 0.45, 0.94);
   }
   .reveal.active {
       opacity: 1;
       transform: translateY(0);
   }
   - يُستخدم على: Stat Cards، Project Cards

د. عداد الأرقام (Counter Animation):
   - الأرقام في قسم الإحصائيات تتحرك من 0 للقيمة النهائية
   - المدة: 2 ثانية
   - يبدأ عند ظهور القسم في الـ viewport (threshold: 50%)
   - يدعم الأرقام مع + و % و /

هـ. تأثيرات كروت المشاريع:
   .project-card:hover {
       transform: translateY(-12px);
       border-color: rgba(99, 102, 241, 0.4);
       box-shadow: 
           0 25px 50px rgba(0, 0, 0, 0.4),
           0 0 40px rgba(99, 102, 241, 0.15);
   }
   
   .project-card::before {  /* الخط العلوي */
       height: 4px;
       background: linear-gradient(90deg, #6366f1, #8b5cf6, #ec4899);
       opacity: 0 → 1 on hover;
   }

و. تأثير الصورة عند Hover:
   .project-card:hover .project-image {
       transform: scale(1.1);
   }

ز. تأثير زر العرض:
   .project-view-btn {
       transform: translateY(30px) → translateY(0);
       opacity: 0 → 1;
   }


6. نظام الفلترة (Filter System)
--------------------------------------------------------------------------------

  - فلتر رئيسي مع فرعيات: "المواقع الإلكترونية" (websites)
      └── فرعي: "التجارة الإلكترونية" (ecommerce)

السلوك:
  - الضغط على "المواقع الإلكترونية" يظهر/يخفي الفلاتر الفرعية
  - أيقونة السهم تدور 180° عند التوسيع
  - الفلتر النشط له خلفية gradient وتوهج

الأقسام المرتبطة:
  - #all-projects: يظهر مع "all" و "websites"
  - #ecommerce-projects: يظهر مع "ecommerce"
  - #service-projects: يظهر مع "service"


7. نظام اللغات (Internationalization)
--------------------------------------------------------------------------------
اللغات المدعومة: العربية (ar) والإنجليزية (en)

التخزين: localStorage.getItem('language')

التبديل:
  - زر في الـ Header
  - يغير lang و dir على <html>
  - يعيد تحميل النصوص والمشاريع

الخطوط:
  - العربية: 'Cairo', 'Segoe UI', sans-serif
  - الإنجليزية: 'Inter', 'Roboto', sans-serif

الترجمة:
  - عناصر بـ data-translate="key.subkey"
  - مثال: data-translate="hero.title"

10. الأداء (Performance Optimizations)
--------------------------------------------------------------------------------
- loading="lazy" على الصور
- will-change: transform على العناصر المتحركة
- Canvas منفصل للـ particles (لا يؤثر على DOM)
- backdrop-filter: blur() للتأثيرات الزجاجية
- Intersection Observer للأنيميشن (بدلاً من scroll events)
- requestAnimationFrame للـ Canvas animations
- إخفاء التأثيرات الثقيلة على الموبايل
